|---------|-----|

| `player-rival.png` | Jugador rival |
| `player-neutral.png` | Jugador neutro |
| `cone.png` | Cono |
| `cone-pole.png` | Pica |
| `seta.png` | Seta de entrenamiento |
| `ball.png` | Balón |
| `goal.png` | Portería |
| `hurdle.png` | Valla |
| `ladder.png` | Escalera de coordinación |

**Reemplazo por el club:** sustituye cualquier PNG manteniendo el mismo nombre de archivo (fondo transparente, ~512×512 px recomendado).
